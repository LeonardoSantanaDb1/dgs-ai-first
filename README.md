# DGS AI First

Repositório utilizado durante a Certificação AI First da DGS para aplicação prática de técnicas de Inteligência Artificial Generativa, Engenharia de Prompt, Engenharia de Contexto, RAG (Retrieval-Augmented Generation), MCP (Model Context Protocol), Agents e Spec Driven Development (SDD).

## Objetivos

- Aplicar conceitos de AI First em cenários corporativos.
- Exercitar o uso de agentes de IA em diferentes papéis de engenharia.
- Estruturar soluções utilizando Spec Driven Development.
- Avaliar técnicas de RAG para recuperação de conhecimento corporativo.
- Explorar governança, skills, MCP Servers e automação assistida por IA.
