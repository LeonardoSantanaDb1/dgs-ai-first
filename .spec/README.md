# Especificações dos Exercícios - Cenário 1

Esta pasta contém os entregáveis finais produzidos durante a execução do Cenário 1 da Trilha de Formação AI First da DGS.

Os documentos aqui presentes representam as versões consolidadas das análises e especificações produzidas a partir das atividades propostas para o papel de Desenvolvedor.

## Estrutura

### Exercício 1.1 - Análise de Viabilidade Técnica

Arquivo:

```text
exercicio-1.1-analise-viabilidade-tecnica.md
```

Objetivo:

Avaliar a viabilidade técnica da construção de um assistente corporativo baseado em IA para a NovaTech, considerando aspectos relacionados a RAG, engenharia de contexto, chunking, retrieval e gerenciamento de contexto.

---

### Exercício 1.2 - Prototipação de System Prompt

Arquivo:

```text
exercicio-1.2-prototipacao-system-prompt.md
```

Objetivo:

Definir e avaliar um System Prompt para utilização pelo assistente corporativo da NovaTech, considerando restrições de negócio, grounding, controle de alucinação e uso adequado do contexto recuperado.

---

### Exercício 1.3 - Especificação do Pipeline RAG

Arquivo:

```text
exercicio-1.3-pipeline-rag-spec.md
```

Objetivo:

Especificar a arquitetura do pipeline de Retrieval-Augmented Generation (RAG), contemplando ingestão documental, indexação, recuperação, montagem de contexto e geração de respostas.

---
